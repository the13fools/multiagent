How an experiment is run

What a cell is, what is paired with what, and whether the campaign can see the effect it was sized for.

Multi-agent results are often reported without their design — the finding and a model name, with no way to tell whether the comparison could have come out otherwise. This is the design, and every number below is computed on the page, from dials you can move.

The unit: one paired cell

A cell is one run of one configuration at one seed. Cells come in pairs: the same environment, the same seed, the same role mapping, with exactly one thing swapped. The measurement is the difference between them, not either number on its own.

Pairing does real work. Variance is large — a paired SD of 1,180 against a 3,363 mean in the pilot — so an unpaired comparison would need several times the compute for the same effect. Pairing removes the seed; what is left is the swap.

The campaign, and whether it is powered

Two numbers decide whether a campaign is worth running: what it costs, and the smallest effect it can see. Affordable and underpowered produces a null nobody can interpret — the ordinary way compute is wasted. Both are arithmetic, so here they are.

The smallest effect this campaign could detect, against how many paired cells it buys. The dashed line is the margin you asked for.

Move the paired SD up and leave the margin alone. The action schema gained a deliberation span and the parser became string-aware after the pilot ran, and either can move the welfare scale — and with it the variance. The requirement rises with the square of the ratio, and a campaign that was comfortably powered stops being so. That is why Phase 0 measures the variance before the powered compute is committed rather than after.

The envelope is fixed and the scope is ordered. The non-negotiable core is gate calibration plus a powered dose-response in the two existing environments: 8,832 cells, 4,416 paired comparisons. Everything else — the other two environments, N ∈ {20, 50}, the new tool-use and memory environments, the mechanism variants — is contingent expansion, dropped in that order if Phase 0 says the core needs the compute. 26,220 GPU-hours all in, about $52k at $1.99 an A100-hour.

The break experiment: pointing the gate at a clone

Everything downstream is a comparison, and a comparison is worth what the rule reading it is worth. The A/A is the cheapest important thing in the plan.

The break experiment

The question How often does our promotion gate reject a candidate that is identical to the baseline?
Why it is free At a seeded fraction of f = 0 no agent occupies the seeded role, so the baseline and candidate configurations describe the same population. They differ only in what an unused role points at. No new engine code, no new environment.
What is measured Every difference between the two arms is noise, so every rejection is a false one. The rejection rate is the false-rejection rate — measured, not assumed.
What it already found Offline, not live. In a sign-flip resampling analysis of the 30-cell pilot, the initial overlap-rule gate rolled back a clone in approximately 100% of null resamples — and gets worse with more data, because it bounds a proportion that converges to 0.5 under the null. The obvious fix, a superiority test, fails for the opposite reason: it demands significant improvement, so a clone fails by construction. A provisional tolerated-harm threshold behaved better under the same resampling (0.076 at n = 30 and 0.015 at n = 60), but it is not yet a formal non-inferiority test.
Status Not yet run live. Everything above is resampling of committed pilot data. Phase 0 runs the matched f = 0 campaigns — both arms and the Firebreak comparison — to measure the live operating error, and the live figure may differ from the offline one.
Pre-registered The live rate will exceed the offline one, and the shipped 400-unit margin will need re-deriving from the measured variance rather than kept. Written down before the campaign runs, so it can be wrong in public.
What it changes Two artifacts ship with the gate that nobody currently publishes: a measured error rate, and a minimum campaign size below which its decisions are void — enforced by the validator, not documented and forgotten.

A gate that rejects everything looks exactly like a careful gate until somebody points it at a clone.

The interactive version — set the true effect to zero and watch three reasonable-looking rules disagree about a clone — is on the gate page.

Pre-registration, and what a receipt contains

Pre-registration here is a versioned plan, not a promise. Before a scored campaign, the plan states the cells, thresholds, estimand, direction of effect, and what would count as no effect. The runner freezes and compares resolved plan files. Commit provenance is recorded in release receipts; enforcing it directly in the runner is remaining hardening work, not a property we pretend is already guaranteed.

Every gate decision emits an auditable JSON receipt — self-contained and versioned, not cryptographically signed — carrying the resolved policy, the paired deltas and the verdict. Our own pilot's policy file changed after the run and the decision was still reconstructible, because the receipt embedded the policy it used. tools/replay_receipt.py re-derives every published figure from the receipt alone. That episode is on the status page under known problems, rather than left for someone else to find.

What could still make the answer wrong

threatwhat we do about it
The threshold is not identifiable at N = 8 Reachable fractions are {0, 12.5, 25, 37.5}%, coarser than the interval of interest. Stated outright: everything at N = 8 is a pilot. Resolution reaches 5 points at N = 20.
One serving endpoint "Different principals" currently means different specifications over identical weights. Cheap seed production is the fix; cross-vendor populations do not exist.
Variance measured at the wrong scale The case above. Phase 0 measures it before the powered campaign is committed.
Small games may not transfer Tested rather than assumed, as contingent expansion: the same question at N ∈ {20, 50}, with the disagreement reported either way. If thresholds do not transfer, that is the finding.
Parse failures scored as behaviour A failure to parse is recorded as an inert action and counted separately, never silently folded into the outcome. The last live sweep had zero.
