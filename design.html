How an experiment is run

What a cell is, what is paired with what, and whether the campaign can see the effect it was sized for.

Most multi-agent results are reported without their design. You get the finding and a model name, and no way to tell whether the comparison could have come out any other way. This page is the design, with the arithmetic exposed: every number below is computed on the page, from dials you can move.

The unit: one paired cell

A cell is one run of one configuration at one seed. Cells come in pairs: the same environment, the same seed, the same role mapping, with exactly one thing swapped. The measurement is the difference between them, not either number on its own.

Pairing is doing real work here. Run-to-run variance in these environments is large — a paired standard deviation of 1,180 against a baseline mean of 3,363 in the pilot — so an unpaired comparison of two campaigns would need several times the compute to see the same effect. Pairing removes the seed from the comparison; what is left is the swap.

The campaign, and whether it is powered

Two numbers decide whether a campaign is worth running: what it costs, and how large an effect it can see. A design where the first is affordable and the second is bigger than the effect you care about produces a null nobody can interpret. That is the ordinary way compute is wasted, and it is arithmetic, so here it is.

The smallest effect this campaign could detect, against how many paired cells it buys. The dashed line is the margin you asked for.

Move the paired SD to 1,820 and leave the margin alone. That is the case the August sweep raised — the welfare scale moved 54% and nobody had yet measured the variance at the new scale. The requirement more than doubles, and the campaign that was comfortably powered stops being so. Required n depends only on the ratio of margin to standard deviation, which is why the plan measures the variance in Phase 0 before committing the compute rather than after.

The compute envelope is fixed. If Phase 0 lands in that case we drop contrasts — one model family instead of two, six fractions instead of eight — and report which, rather than raising the ask.

A control is only worth its compute if you can name the alternative explanation it kills. Each of these exists because a specific one would otherwise survive.

Pre-registration, and what a receipt contains

Pre-registration here is git history, not a promise. The campaign plan — cells, thresholds, the estimand, the direction of effect and what would count as no effect — is committed before the first scored run, and the run refuses to start into a campaign directory whose committed plan differs from the one in hand.

Every gate decision emits a signed JSON receipt carrying the resolved policy, the paired deltas, and the verdict. That matters more than it sounds: our own pilot's policy file changed after the run, and the decision was still reconstructible because the receipt embedded the policy it actually used. tools/replay_receipt.py re-derives every published figure from the receipt alone, without the run directories.

That episode is on the status page under known problems, rather than left for someone else to find.

What could still make the answer wrong

threatwhat we do about it
The threshold is not identifiable at N = 8 Reachable fractions are {0, 12.5, 25, 37.5}%, coarser than the interval of interest. Stated outright: everything at N = 8 is a pilot. Resolution reaches 5 points at N = 20.
One serving endpoint "Different principals" currently means different specifications over identical weights. Cheap seed production is the fix; cross-vendor populations do not exist yet.
Variance measured at the wrong scale The case above. Phase 0 measures it before the powered campaign is committed.
Small games may not transfer Tested rather than assumed: the same question at N ∈ {8, 20, 50}, with the disagreement reported either way. If thresholds do not transfer, that is the finding.
Parse failures scored as behaviour A failure to parse is recorded as an inert action and counted separately, never silently folded into the outcome. The last live sweep had zero.
