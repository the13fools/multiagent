Environments

environmentstatuswhat exists
Shared Resourceworking Binary action, upkeep, permanent death. Closed-form solution, closed-form carrying capacity, and an unwinnable control condition. Every arithmetic claim asserted by flockbench-shared --selftest.
Commons Harvestworking Logistic regrowth with continuous harvest. Shipped at ceiling-to-upkeep 0.39 until 6 Aug — collapse guaranteed for every strategy, so composition could not matter and those cells measured nothing. Defaults now sit at 1.56, where restraint sustains indefinitely and full defection still starves. A scarcity config keeps 0.39 deliberately, as the other arm of RQ5. A test fails any default config below 1.0.
Public Goods + punishmentworking Herrmann-shaped, 20 rounds, contribute and punish stages. This is what the Stage Zero pilot ran on.
Boardwalkanalysis only The equilibrium census is verified by brute force and the dynamics run in the browser. It is not wired to a serving endpoint, so no language model has ever played it.
Tool use · persistent memorynot built Named as Phase 1 deliverables. Nothing exists.

Runs against live models

runstatuswhat it showed, or would
Stage Zero pilot
30 matched PGG cells, 1 Aug		 complete Zero parse failures across both arms. The gate emitted a rollback receipt citing four violated constraints. Auditing that decision is where the calibration result came from. The receipt embeds its resolved policy and all 30 paired cells, so the statistics are reproducible without the run directories — which is fortunate, because those were never tracked.
End-to-end Commons
1 seed, 14 Jul		 one seed Seeded agents delayed collapse to round 9 against round 7 for the control, and doubled restraint under scarcity. One seed and one adapter. Enough to show the pipeline runs end to end; not enough to estimate an effect, and we do not claim one.
Deceptive-alignment adapter
14 Jul		 complete An adapter trained on judge-selected pairs — 27% of the chosen examples from a deceptive-alignment persona a two-judge panel rated 4/5 — collapsed the commons faster than unmodified base, and was indistinguishable from a random-selection control. The panel checked for coherent planning, not for whether the plan was aligned.
f = 0 sweep, one arm
30 cells per game, 6 Aug		 complete Zero parse failures in both games. First live run since the reasoning span entered the action schema and the JSON parser became string-aware, so both changes are validated against real model output. PGG welfare 5,189 and unravelling slope +0.134 — contributions rising, and 54% above the pilot's 3,363 baseline. Commons collapsed at round 3.0 in all 30 seeds with survival 0.0, which is the degenerate configuration behaving exactly as its arithmetic predicted.
Live A/A calibrationone arm of two An A/A needs two campaigns — baseline and candidate, identical at f = 0 except the seeded role mapping — then Firebreak comparing them. One arm exists. Until the second runs and the receipt is written, the gate's error rate is still resampled from the pilot's deltas rather than measured. run_aa_calibration.sh does both arms and the comparison.
Style positive controlrig built, not run Training harness exists in continuous_judge; the flockbench bridge is committed. The prompted variant needs no training at all. Not yet executed against a live endpoint.
Powered dose-responsenot run The campaign the proposal is asking to fund. ~69 paired cells per contrast at the pilot's variance — 400 units of margin against a paired SD of 1,180. Required n depends only on that ratio, so if Phase 0 finds the SD scaled with the welfare mean and the margin did not, the same design needs ~163. The compute envelope is fixed either way; contrasts get dropped before the ask goes up.
Scaling, N ∈ {8,20,50}not run Configs for N=20 exist. Nothing has been run above N=8.
The Count
shared-deck betting game		 sketch Rules, both closed-form answer keys and the policy comparison exist and are tested; a browser sketch runs them. No language model has played it and it is not wired to a serving endpoint. It is the only environment here that separates reasoning about the environment from reasoning about the other players, which is why it is worth finishing.
Communication channels
public tally, commitment, private pair		 not built The second rung of the ladder and the first place a question about communication could be asked while the right answer is still known. A private pairwise channel is also the specific thing this testbed would need before it could claim anything about collusion. None of it exists: today the agents cannot talk to each other at all.
Negotiation-scale games
Diplomacy, Utopia-scale		 direction only Named as where the instrument gets pointed once it is trustworthy. No code, no plan beyond the ladder, and no answer key when it gets there — which is the whole reason for being strict about the small games first.

Which claims rest on what

claimevidencestrength
A solution exists; slack is zero at the reference parameters; carrying capacity is closed-formarithmetic Provable, and asserted in two independent implementations that the test suite pins to each other. Not contingent on any model behaving any way.
Conformist populations need 75% of seats to steer simulation True of the scripted follower rules. No language model has been measured against it. Which rule real models implement is the open question, not a finding.
A flock of Qwen2.5-7B takes every turn and dies by turn 14 observed Observed behaviour, small number of runs. Robust in direction, not yet quantified with confidence intervals.
The pilot gate rolls back a clone of its own baseline ~always resampled Computed by resampling the pilot's real paired deltas under the null, and reproduced by two independent implementations. Strong, but not the same as a live A/A campaign, which is why Phase 0 exists.
Non-inferiority gates pass A/A from n = 60 resampled Same basis as above. The number to trust after Phase 0, not before.
A distinct fine-tuned agent costs about $50 one receipt A real measurement from one setup — Qwen2.5-7B, LoRA, our hardware, one month's GPU prices. Not a projection and not a law. The question worth answering is not the price but the floor: how little training still leaves agents usefully distinct from each other. Unmeasured.
Small per-step bias is invisible early and fatal late predicted Shown in the juggling sketch, which is our own construction and is off the main path for that reason — it is an analogy, not an instrument. It also follows from the shared-resource arithmetic, where an agent off p_need by any margin dies on a schedule. Whether real agent populations show the horizon dependence is Phase 3 and untested.

Known problems we have not fixed

  • The pilot's promotion policy was not committed before the run. It is recoverable and machine-verifiable from the receipt, which embeds the resolved policy — but for that one run, "thresholds committed before evaluation" is backed by the receipt rather than by git history. Disclosed rather than discovered.
  • The threshold is not identifiable at N = 8. Reachable fractions are {0, 12.5, 25, 37.5}%, coarser than the interval of interest. Everything at N=8 is a pilot by construction.
  • One serving endpoint. "Different principals" currently means different specifications over identical weights. Cheap seed production addresses this; cross-vendor populations do not exist yet.
  • No test suite in continuous_judge. The other repositories have one.
  • The non-inferiority margin may be stale. It was set at 400 welfare units, 11.9% of the pilot's 3,363 baseline. The 6 Aug arm came in at 5,189, which would make the same margin 7.7% — so the margin and the power analysis both need recomputing against the new variance before the powered campaign runs.

What would change this page fastest

One GPU session. The A/A campaign and the prompted style control are both committed and preflight-checked. Between them they move four rows from resampled to measured, including the two the gate argument rests on. Neither needs new code.

If a row here disagrees with something in the proposal, this page is right and the proposal is stale. Please tell us.
