The experiment

Does adding a small number of cooperative agents change the fate of a population that otherwise exhausts a shared resource?

Hypothesis

In a mixed population of language-model agents, increasing the fraction of agents given a meaningful cooperative policy will move the group from collapse toward sustained resource use. The fraction required may depend on population size, resource slack, and what the unseeded agents can observe.

What changes—and what stays fixed

A matched pair uses the same model-serving stack, game, seed, role order, prompt scaffold, decoding settings, and horizon. The only change is the policy assigned to selected seats.

ArmWhat it tests
BaseThe population with no intervention.
Decision-rule seedWhether a transparent policy can change collective behavior.
LoRA seedWhether a trained version of the same behavioral input changes the result.
Vocabulary-matched mimicWhether an apparent effect is merely the language or tone of the intervention.

What we measure

The environment scores the run: who survives, when the pool collapses, total welfare, inequality, the resource trajectory, and deviation from the restoration rate needed to sustain the commons. We save prompts, replies, parsed actions, and state transitions. A parse failure is counted and assigned an inert action; it cannot become accidental evidence of cooperation.

First, calibrate the measurement

Before evaluating a seed, we run an A/A campaign: candidate and baseline are the same population. Any rollback is a false rejection. The primary calibration plan is 60 independent A/A campaigns of 60 matched pairs on Qwen2.5-7B-Instruct in the binary game. If none roll back, the one-sided exact 95% upper bound on the campaign-level false-rejection rate is 4.9%.

This step is necessary because the offline audit already found a bad rule: the original overlap gate rolled back a clone of its baseline with probability 1.000 under sign-flip resampling of a 30-cell pilot. That is a warning about the instrument, not a result about the intervention.

Then, estimate a dose response

We sweep the fraction of seeded agents at N=8, then repeat the informative range at N=20 and N=50. We compare zero-slack, positive-slack, and unwinnable resource settings. The output is not a single dramatic threshold: it is a set of paired estimates and confidence intervals showing whether the effect is robust, conditional, absent, or harmful.

What would count as success?

Best case: the seed improves survival and welfare beyond the mimic arm across model families and larger populations, with a calibrated gate and a transparent mechanism.

Still valuable: a precise null, a result that only works at N=8 or in abundance, or evidence that the gate cannot be calibrated. Each rules out a tempting but unsupported claim about population-level alignment.
