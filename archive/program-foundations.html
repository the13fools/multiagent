The Commons Game, solved as far as it goes

One number says whether a parameter set can measure anything.

Regrowth is logistic: g(S) = rS(1 − S/K), peaking at S = K/2 where it equals rK/4. If required draw exceeds that peak, no policy can sustain the population.

Below a feasibility ratio of 1, the seeded fraction cannot matter. The project shipped a default at 0.39 for months; an f = 0 sweep later confirmed collapse at round 3 for all thirty seeds. The core campaign now runs only above 1, with the impossible regime retained as a small control.
