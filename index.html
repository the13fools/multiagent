Can a few AI agents prevent a shared resource from collapsing?

That is the whole question. flockbench makes it measurable in a game with a known answer.

The game

Eight agents share a pool. Every turn, each pays 1 token to stay alive and chooses:

Restore: pay 1 token; add 3 to the pool.

Take: take 3 tokens from the pool.

Everyone survives forever if each agent alternates restore and take. The pool stays level and every agent breaks even. At the reference setting, one permanent taker eventually kills the entire group. There is no ambiguity about what success requires.

Why this is useful

Most multi-agent evaluations cannot distinguish a group that coordinated badly from a group facing an impossible task. Here the sustainable policy, the required restoration rate, and the failure condition are all fixed by arithmetic. The score is the environment itself: survival, welfare, pool level, inequality, and time to collapse. No LLM judge decides who behaved well.

What the pilot found

A one-seed run with eight Qwen2.5-7B-Instruct agents completed end to end with zero parse failures. A seeded LoRA adapter delayed stock exhaustion relative to its control. That shows the pipeline works; it does not establish an effect size, a threshold, or generalization.

Not established yet: the fraction of agents needed to move a population from collapse to sustained resource use. This is a composition question, not an individual-agent alignment claim. The first methodological result is equally important: an offline audit found that the original promotion rule would roll back a clone of its own baseline almost certainly. The live A/A calibration has not run, so the experiment must calibrate its measurement rule before using it to judge an intervention.

The proposed experiment

  1. Calibrate the gate. Run A/A campaigns where candidate and baseline are identical; every rollback is a false rejection.
  2. Vary the seeded fraction. Compare base populations, a transparent cooperative policy, a trained adapter, and a vocabulary-matched mimic.
  3. Find the boundary. Repeat at larger population sizes and under feasible, forgiving, and unwinnable resource conditions.

The result can be positive, null, or adverse. The useful output is a composition-response curve with confidence intervals and a clear account of where it does—and does not—transfer.
