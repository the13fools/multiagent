Can a small minority of AI agents keep a shared resource alive?

flockbench starts with a game simple enough to solve on paper, then asks whether a population of language-model agents can find—or be steered toward—the solution.

The game

Eight players share a pool. Each turn, a living player pays 1 token to survive and chooses one action: pay 1 more token to add 3 tokens to the pool, or take 3 tokens from it. A player whose balance falls below zero is removed.

The sustainable policy is not mysterious: players alternate restoring and taking. Each individual breaks even; the pool breaks even; everyone can live indefinitely. At these parameters there is no slack: one permanent taker eventually kills the whole group. The right answer is therefore known before a model is queried.

The scientific question

If most seats belong to agents we do not control, what fraction of carefully specified agents is enough to move the population from collapse to sustained cooperation?

That is a composition question, not a claim that one agent is "aligned." We hold the game, model-serving stack, seed, and scoring fixed; vary population composition; and measure the resulting arithmetic.

Why this is a useful first test

Real deployments will place agents from different developers in shared settings: budgets, compute, queues, markets, data stores, and protocols. Those systems are more complicated than this game. But complexity creates a basic problem: when a population fails, it is often unclear whether the agents chose badly or whether success was impossible. Here, the feasible region and the failure condition are explicit. That lets us calibrate an evaluation instrument before we ask it a harder question.

flockbench scores outcomes with environmental arithmetic—pool level, survival, welfare, inequality, and distance from the required restoration rate—not an LLM judge. Every action and payoff can be replayed from a trace.

The proposed study

1 · Calibrate the instrument

Test the promotion gate on clones

Run repeated f = 0 A/A campaigns, measure false rejection, and publish its uncertainty before using the gate on a candidate.

 2 · Test a dose response

Vary the fraction of seeded agents

Compare a transparent decision-rule seed, a trained adapter, and a vocabulary-matched mimic under the same game conditions.

 3 · Map the boundary

Change scale and scarcity

Measure whether the composition threshold changes across population sizes, resource regimes, and model families—or fails to transfer.

The aim is deliberately modest and falsifiable. We are not claiming that a toy game predicts social life, nor that a prompt makes an agent safe. We are building a calibrated way to learn whether a specific intervention changes a specific collective outcome. A clear null, a failure to transfer, or a gate that cannot be calibrated are all useful results.
