The funded questions

Three questions, in scientific order.

The controlled fraction means nothing unless the decision rule works, the population response can be estimated, and the majority mechanism explains when a minority propagates.

RQ1 · 17%

Can the decision rule be trusted?

Point the rule at a clone — both arms from the same population at f = 0 — so every rollback is false by construction. Three rules a careful person might write:

rule10 pairs200 pairs
Overlap — most cells must not regress95%100%
Significance test — candidate must win99%96%
Tolerated-harm threshold16%0%

The overlap rule gets worse with more evidence — it bounds a proportion converging to one half under the null. The significance test fails oppositely: it demands an improvement, so a clone never passes. A gate should ask whether a swap is safe to ship, not whether the candidate is better. Thirty live f = 0 campaigns of 60 pairs measure the real rate; an upper confidence bound above 10% retires the gate before any candidate claim.

RQ2 · 44%

How large a minority is needed?

f* = inf{ f : Δ(f) ≥ δ } — the smallest controlled fraction whose paired gain in survival clears the margin. δ is not chosen for convenience: it is the survival decrement one more permanent defector causes among eight. The arithmetic follows — 69 paired cells per contrast, and the design buys 70.

Isotonic regression over the fraction, cluster bootstrap for the interval, monotonicity test first: if survival is not monotone in f, f* is undefined and the raw curve is the finding. Not theatre — Stage 0's ordering flipped when one environment parameter moved. f* is estimated separately by game, family and slack level, never averaged; N = 8, 20 and 50 test whether it moves with size, which does not claim a scaling law.

RQ3

What does the majority do with the signal?

RQ2 has no single answer, because it depends on the agents you do not control. The model on the overview sizes that dependence: same game, same horizon, change only the majority's rule, and the seats you need swing from none to all eight. A majority watching the pool needs no coalition; one copying its neighbours needs six of eight; pure takers need everybody.

So the rule is a designed factor. Scripted majorities use four declared rules — imitate-best-neighbour, tit-for-tat, myopic-greedy, random — known by construction, and they are the answer key for the classifier that infers the rule in LLM populations: accuracy measured against known labels before use, that error carried into the estimate. Pre-registered: f* will be lowest under imitate-best-neighbour majorities and highest under myopic-greedy, because imitation propagates a minority and greed does not.

Progressive Denoising Distillation (PDD)

A low-cost way to create strategy pools, not one universal agent.

Begin with a failure to change: the model sees a low pool and chooses take. PDD builds a target around a desired restore, inpaints only its rationale, and trains on accepted replacement words alone. Whether the behaviour shifts is an evaluation question.
