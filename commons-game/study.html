The funded questions

Three questions, in scientific order.

The pilot supplies a failure worth explaining, not a treatment effect. The funded study first validates its decision rule, then estimates the population response, then asks which behaviors in the uncontrolled majority transmit or resist a trained minority.

RQ1 · VALIDITY

Can we distinguish a safe replacement from noise?

Why it comes first. A deployment gate can look conservative while rejecting harmless changes almost every time. Before evaluating a trained policy, compare two arms sampled from the same population at f = 0. In this clone condition there is no treatment, so every rollback is a false alarm by construction.

What is measured. Thirty live clone campaigns of 60 matched pairs estimate the gate's false-rollback rate under the same serving stack used later. The gate asks whether a swap is acceptably safe, not whether a candidate is guaranteed to be better.

Failure condition. An upper confidence bound above 10% retires the gate before any candidate claim. This prevents a broken safety rule from manufacturing a negative result.

RQ2 · THRESHOLD

When does a controlled minority change survival?

The quantity. f* = inf{ f : Δ(f) ≥ δ } is the smallest controlled fraction whose paired survival gain clears a predeclared practical margin. The margin is tied to the harm caused by adding one permanent defector to an eight-agent game, rather than chosen after seeing the curve.

How it is measured. Sweep the controlled fraction with matched seeds and estimate the dose-response curve. The power calculation requires 69 paired cells per contrast; the design buys 70. Isotonic regression estimates f* and a cluster bootstrap carries uncertainty from whole rollouts rather than treating turns as independent observations.

Failure condition. Test monotonicity first. If survival rises and then falls as control increases, f* is undefined and the raw nonmonotone curve is the result. Estimates remain separate by game, model family, and resource slack. N = 8, 20, and 50 test whether the threshold moves with population size; that comparison does not claim a scaling law.

RQ3 · MECHANISM

Which majorities transmit—or resist—the minority?

Why the threshold is contextual. The agents outside the controlled set are part of the treatment environment. In the overview model, changing only their response rule moves the required coalition from none to all eight seats. Reporting one population-wide f* would hide the mechanism.

The answer key. Start with scripted majorities whose rules are known by construction: imitate-best-neighbour, tit-for-tat, myopic-greedy, and random. Those labelled runs validate the behavioral classifier before it is applied to LLM populations; classification error is then propagated into the threshold estimate.

Pre-registered mechanism claim. f* will be lowest under imitate-best-neighbour majorities and highest under myopic-greedy majorities, because imitation can amplify a minority while greed does not. If the ordering fails, the study reports the observed mechanism instead of preserving the story.

Progressive Denoising Distillation (PDD)

A low-cost way to create strategy pools, not one universal agent.

We wanted to train many distinct commons-game personas without repeating a full-model fine-tune. The prototype uses a diffusion language model as an LLM-as-a-Judge: it inpaints rationale around a fixed target action, filters the proposed words, and distills accepted replacements into small LoRA adapters.

01 · aim

One base, many strategies

Create cheap adapters whose behavior differs because of learned updates, not merely a persona prompt.

02 · source-game result

Longevity improved once

In the Commons Game—logistic stock regrowth and a harvest bid from every agent each turn—the trained diagnostic trace reached round 170 instead of round 33 for the baseline.

03 · simpler answer key

Training found the wrong extreme

In Shared Resource, the sustainable population alternates give and take. Both trained flocks instead gave every turn and all agents died by round 6.

Open scaling question

How cheaply can one base model become a heterogeneous flock?

The one measured anchor is a Stage 0 receipt: one Qwen2.5–7B adapter cost about $50. At $2 per hour for an 80 GB GPU, that is roughly 25 GPU-hours. The calculator asks how that measured unit scales with the number of personas and independent training repetitions. It does not infer runtime from parameter counts or nominal token throughput.

826 adapter trainings is the theoretical maximum if the entire $41,330 compute line were spent at this rate—equivalent to 826 personas at one training each. $39,830 remains for evaluation rollouts and other compute.

What this includes: adapter-training compute only. Multi-agent evaluation rollouts, commercial APIs, storage, and labor are separate. Only the 7B receipt is measured; larger-model factors are rough planning assumptions. Lowering hours per adapter buys a larger flock, but below an unknown floor the “personas” may be indistinguishable copies with different accents. Measuring that diversity floor is the research question.

The calculator now computes a planning cost, not a training-time prediction. The proposed work measures which quantities—PDD steps, sequence construction, model size, and LoRA configuration—actually move the receipt, then tests whether cheaper adapters remain behaviorally distinct at population scale.
